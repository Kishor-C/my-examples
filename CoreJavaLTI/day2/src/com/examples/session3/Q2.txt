Single File Programming Question
Row wise 2D Array sort



Problem statement

Implement the given function,

int[][] sort2DArrayByRow(int m, int n, int[][] arr);



The function accepts a two-dimensional integer array arr of m rows and n columns. Implement the function to return the 2D array after sorting each row of the array arr in ascending order.

Note:

You need to sort each row in ascending order.



Example

Input

3

4

7 9 2 4

3 2 5 4

9 7 8 1

Output

2 4 7 9

2 3 4 5

1 7 8 9



Explanation:

Sorted the first, second, and third rows in ascending order.

Input format :
The first integer represents the number of rows m.

The second integer represents the number of columns n.

The next m x n values represent the elements of the matrix.

Output format :
The output should be the matrix after sorting each row in ascending order, printed row by row.

Code constraints :
m > 0 and n > 0

Array index starts from (0, 0)
