Single File Programming Question


Problem Statement:
You are developing a simple text analyzer that processes sentences to evaluate their structure based on the following criteria:

The sentence must start with a capital letter.
The sentence must end with a punctuation mark (., ?, or !).
The sentence must contain at least one vowel (a, e, i, o, u).
The sentence must not contain any digits.
Write a program that processes a list of sentences and checks each one against these criteria.

Input format :
The first line contains an integer n, the number of sentences.

The next n lines contain one sentence each.

Output format :
Output Format:
For each sentence, print whether it is valid or invalid based on the criteria.

Valid: The sentence must start with a capital letter, end with a punctuation mark (., ?, or !),contain at least one vowel (a, e, i, o, u)and no digits.



Code constraints :
Constraints:
The number of sentences (n) ≤ 50.
Each sentence length ≤ 100 characters
Sample test cases :
Input 1 :
3
This is a valid sentence.
this is not valid
Another valid sentence?
123 This should be invalid!
Output 1 :
Sentence: This is a valid sentence. - Valid
Sentence: this is not valid - Invalid
Sentence: Another valid sentence? - Valid
Input 2 :
4
Hello world!
Good morning?
how are you
I love programming.
Output 2 :
Sentence: Hello world! - Valid
Sentence: Good morning? - Valid
Sentence: how are you - Invalid
Sentence: I love programming. - Valid
